【北京地铁路径规划系统项目介绍】本项目打造面向用户的北京地铁智能路径规划平台，系统依据乘客日常出行查询需求，对业务功能进行合理划分。系统支持地铁线路查询、站点信息检索、最短路径规划、最少换乘方案推荐及全站点遍历等功能，满足用户日常地铁出行的路线规划与信息查询需求。后端采用Dijkstra最短路径算法与BFS广度优先搜索算法实现多策略路径规划，保障查询结果的准确性与响应速度。

【开发技术栈】Node.js, Express, MySQL, HTML5, CSS3, JavaScript, Dijkstra算法, BFS算法.

【部分核心功能实现】
· 多策略路径规划引擎：基于Dijkstra最短路径算法实现最少站点数路径查询，同时基于BFS广度优先搜索（以换乘次数为权重）实现最少换乘方案推荐，满足用户不同出行偏好，提升路线规划灵活性。
· 地铁数据建模与存储：采用MySQL构建包含线路表(lines)、站点表(stations)、线路站点关系表(line_stations)及连接表(connections)的关系型数据模型，完整覆盖北京地铁多条线路的拓扑结构与站点连接关系，为算法提供精准数据支撑。
· 站点线路交叉查询：支持按站点查询途经线路、按线路查询所属站点及换乘站识别功能，提供多维度地铁信息检索能力，方便用户快速了解地铁网络全貌。
· 全站点遍历功能：实现从指定站点出发遍历所有地铁站点的路径规划，支持线路运营管理与应急场景下的全局路径参考需求。
